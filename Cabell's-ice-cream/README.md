# 🍦 AI Ice Cream Shop

A modern **Ice Cream Shop Web Application** built using **React** with **AI-powered features**.
This project provides an interactive shopping experience where users can explore ice cream flavors, browse menu items, and interact with an AI assistant for recommendations.

---

# 🚀 Features

* Responsive modern UI
* Interactive ice cream menu
* Category filtering
* AI chatbot assistant
* Smooth navigation
* Product cards with pricing
* Friendly and colorful design

---

# 🧠 AI Assistant

The website includes an **AI-powered assistant** that helps users:

* Ask about available ice cream flavors
* Get menu recommendations
* Learn about shop hours
* Discover popular items

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/ai-icecream-shop.git
```

Go to project folder

```bash
cd ai-icecream-shop
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm start
```
