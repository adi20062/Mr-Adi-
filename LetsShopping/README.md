# 🛒 Shopping Website

A simple **Shopping Website** built using **HTML, CSS, and JavaScript**.
This project demonstrates a basic e-commerce interface where users can browse products, add items to the cart, and view their cart.

The project focuses on **frontend functionality** and uses **browser localStorage** to store cart data.

---

# 📌 Features

* Responsive shopping UI
* Product listing page
* Add to cart functionality
* Remove items from cart
* Cart item counter
* Data stored using **localStorage**
* Simple and clean design
